# PCEDUC - Aprendizagem de Hardware

Uma proposta de aplicativo educacional que torna o aprendizado de hardware mais dinâmico, interativo e envolvente por meio da gamificação.

## 📋 Sobre o Projeto

O PCEDUC é um projeto de extensão voltado à educação em hardware. A ideia é oferecer uma experiência de aprendizagem inspirada em aplicativos de idiomas como o Duolingo, adaptada para apresentar conceitos de hardware de forma acessível e estimular o progresso por meio de atividades gamificadas.

O projeto está atualmente na etapa de concepção e prototipação das telas. O material disponível representa uma proposta visual e de interação, não uma aplicação finalizada ou disponível para uso.
