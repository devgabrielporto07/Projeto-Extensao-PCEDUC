# Telas do app (galeria do site)

Coloque aqui as telas do protótipo do PCEDUC para a galeria do site.

1. No [Figma](https://www.figma.com/proto/Nds3cFqZtrh3N2oKh1um8q/Telas-PCEDUC?node-id=10-2&t=ofcFB11myQ6Vvf07-1),
   selecione cada frame e use **Export → PNG** (2x).
2. Salve com nomes em sequência: `tela-01.png`, `tela-02.png`, `tela-03.png`...
3. Liste cada arquivo (com uma descrição para o `alt`) no array de telas do `site/js/main.js`.

Enquanto a imagem não existir, a galeria mostra o espaço reservado "Tela em breve" (RN003).
